The interface now groups metadata with spacing and alignment instead of dot separators.
Repeated status labels, extra version hashes in the Library, and decorative equation
markers have been removed. Commit selection, comments, and earlier rounds remain available.

Source changes retain their red and green highlights. Native control conventions,
keyboard decisions, passage editing, and applying a review work as before. Existing
libraries need no migration; saved reviews and manuscripts stay outside the app bundle.

Quit the app before replacing it. Download the app ZIP and move the app to
**Applications**. See the
[installation guide](https://github.com/njwfish/manuscript-review/blob/main/docs/INSTALL.md).
The app supports Apple Silicon Macs on macOS 13 or later. It is locally signed and
has not been notarized. The browser interface runs from source on macOS and Linux
with Git and Python 3.12 or later.
