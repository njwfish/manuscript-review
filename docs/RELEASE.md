Manuscript Review 0.14.8 includes the standalone macOS app and VS Code extension 0.1.15, built from the same commit. Both interfaces and the shared engine are maintained on `main`.

This release fixes typeset previews for accented math commands and isolates malformed excerpts so other previews remain available. Reference builds and PDF/SVG bytes are reused by source version. Interactive data loads source files on demand; status and preview polling use small responses. Git comparisons read source blobs in bulk, and record and library caches invalidate when their files change.

Comment dispatch in both interfaces now uses the selected Codex or Claude Code CLI in the background, keeping author focus in the manuscript. Agents can revise isolated proposal checkouts while the author continues reviewing or editing. Clean results accumulate as undecided changes in the same comparison against its fixed base, preserving existing decisions, drafts, and discussion. Different words in one paragraph can merge; overlaps require reconciliation. Author files and buffers stay untouched until **Apply**. Final responses remain in the comments; working transcripts stay with the provider.

The VS Code sidebar's **Review highlights** switch disables diff highlighting and surrounding dimming independently of **Source comments**. Source enumeration respects ignore rules, hidden and temporary directories, and nested repositories without restricting file types. Existing reviews and their source snapshots are retained.

Download the app ZIP for Apple Silicon macOS 13 or later, or install the `.vsix` through **Extensions → Install from VSIX…**. The extension runs independently on macOS and Linux with Git and Python 3.12 or later. [Installation](https://github.com/njwfish/manuscript-review/blob/main/docs/INSTALL.md) covers prerequisites and agent skill setup; the [VS Code guide](https://github.com/njwfish/manuscript-review/blob/main/vscode/README.md) and [standalone guide](https://github.com/njwfish/manuscript-review/blob/main/README.md#review-in-the-standalone-app) describe the review cycle. Reload VS Code after updating. **Setup and agent skill** refreshes the bundled instructions and command launcher.

Reviews from 0.14.2 or newer need no format migration. For older libraries, close review windows and run the bundled agent command with `migrate` before reopening. The migration preserves decisions, comments, replies, source versions, and drafts, retains original records, and leaves manuscript files unchanged. [Upgrade instructions](https://github.com/njwfish/manuscript-review/blob/main/docs/INSTALL.md#upgrade-an-existing-library) cover both installations.

The macOS app includes Python and is locally signed, without notarization. LaTeX and Poppler are optional for typeset and PDF previews. The browser interface runs from source on macOS and Linux. Review state stays in the local library; replacing either package preserves it.
