The review interface now puts the manuscript first: borderless passages, a compact
toolbar, a quiet file list, and neutral macOS colors in light and dark appearances.
Repeated headings, counters, and shortcut instructions have been removed from the
reading view. Secondary tools remain available under **⋯** and **?**.

Prose uses a narrow reading column; side-by-side LaTeX previews have more room.
Raw LaTeX and passage editing use monospace. The Library uses a simple manuscript
list with earlier rounds under **History**.

Keyboard decisions, passage editing, comments, replies, and applying a review work
as before. Existing libraries need no migration. Quit the app before replacing it;
saved reviews and manuscripts stay outside the app bundle.

Download the app ZIP and move the app to **Applications**. See the
[installation guide](https://github.com/njwfish/manuscript-review/blob/main/docs/INSTALL.md).
The app supports Apple Silicon Macs on macOS 13 or later. It is locally signed and
has not been notarized. The browser interface runs from source on macOS and Linux
with Git and Python 3.12 or later.
